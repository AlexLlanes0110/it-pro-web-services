# Roadmap — ITPro Web

## V1 — Current target

Spanish one-page landing page.

Must include:

- Fixed header
- Internal anchor navigation
- Floating WhatsApp button
- Hero
- Problem section
- Services section
- How we work section
- Generic real case
- Technology philosophy
- Founder section
- Contact section
- Footer
- Responsive layout
- Basic SEO
- Basic Open Graph
- AWS deploy readiness

Out of scope:

- Blog
- CMS
- Client portal
- Login
- Tickets
- Database
- Payments
- Complex forms
- Chatbot
- Multi-language active support
- Docker

## V1.5

Add multi-language support:

- `/` for Spanish
- `/en/` for English
- ES/EN language switch
- hreflang
- Open Graph per language
- Simple analytics
- Named case study with logo only if authorization exists

## V2

Convert the codebase into a reusable one-page landing page template.

Goals:

- ITPro theme
- Demo grayscale theme
- Generic images
- Decoupled content
- Theme system
- Possible separate repo or branch
- Template to sell one-page landing pages to other clients
