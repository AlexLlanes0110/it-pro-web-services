# UX Review Prompt — ITPro Web

Review the landing page UX for a PyME business owner.

Evaluate:

- Clarity of the main message
- Whether ITPro sounds like a technology partner, not computer repair
- CTA visibility
- WhatsApp conversion path
- Section order
- Trust and credibility
- Founder positioning
- Mobile experience
- Visual hierarchy
- Copy clarity

Return:

1. What works
2. What is confusing
3. What should be simplified
4. Conversion improvements
5. Recommended section-level changes
